# IbaGO React

Proyecto de turismo cultural para Ibagué desarrollado con React, Vite y Tailwind CSS.

## Scripts

- `npm install` - Instalar dependencias
- `npm run dev` - Ejecutar en desarrollo
- `npm run build` - Construir para producción
- `npm run preview` - Vista previa de producción

## Desarrollo

El proyecto utiliza React Router para navegación y Google Maps para mostrar lugares turísticos de Ibagué.
